# V4.4 F3 — Formace jako akrece (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Přepsat formation intro z „Slunce vystřeluje planety po dávkách" na reálný akreční narativ: protoplanetární disk → zážeh Slunce ze středu → planety se **souběžně** zhušťují z prstenců disku na svých reálných (ephemeris) pozicích → plynulý přechod do živého stavu. K tomu geologická časová osa v HUD a zamčený scrubber během formace.

**Architecture:** `animation.js` dostane novou beat timeline (disk → zážeh → akrece → měsíce → live) + `ACCRETION_WINDOWS` (překrývající se emisní okna per planeta). `formationIntro.js` se přepíše: řídí disk, zážeh i akreci — tečky planet emituje z lokální zóny disku (`pool.spawnFromDisk`, zdroj = okolí planety, ne Slunce), 12k prachových částic vizuálně migruje do planet/Slunce. `solarWind.js` (jen planet-emise ze Slunce) se maže; nový `sunWind.js` = decentní ambientní vítr ze Slunce. `formationTimeline.js` mapuje beaty na geologické popisky. `main.js` drží lifecycle: start = pauza na dnešním datu + zamčený scrubber, `done()` = `simClock.play()` + odemknout.

**Tech Stack:** Vanilla JS ES modules, Three.js 0.184 (vendored), astronomy-engine (vendored), `node --test`, pixel HUD (Press Start 2P).

## Global Constraints

- **Reálný model:** cíle akrece = pozice z `positionProvider` pro dnešní datum (přes anchory, které je už mají). Žádné vymyšlené dráhy. Konec akrece = planety přesně na ephemeris pozicích (žádný skok při přechodu do live).
- **Žádné dávkování ze Slunce:** planety se hustí **současně** z prstenců disku (okna se překrývají, vnitřní začínají dřív). Ze Slunce nesmí letět žádná planetární tečka.
- **Formace jede na `_realElapsed`** (real-time, vždy dopředu, nereversuje). simClock je během formace pauznutý; scrubber + klávesy času zamčené (spec E6). Scrub nikdy nespouští formaci znovu; restart formace (klávesa R) je **out-of-scope F3** (F4).
- **Aktivita Slunce zůstává:** `sunActivity.js` (spoty/prominence/CME) beze změny. Ambientní vítr = nový `sunWind.js`, běží na `dtRealMs` nezávisle na simClocku.
- **Přechod do live:** `done()` → `simClock.setDate(new Date()); simClock.play()`; pozice převezme ephemeris bez skoku (formace celou dobu cílí na dnešní pozice a simClock je pauznutý na dnešním datu).
- **Geologické popisky** (formationTimeline) přesně dle specu §6 F3 tabulky — fáze jsou narativní, ne přesné datování.
- **Výkon:** pool 600 000; per-frame JS smyčky jen přes 12k prachu (ne přes 328k planetových teček). FPS nesmí viditelně klesnout proti dnešku.
- **Offline + CSP** zachováno; žádné externí zdroje. `npm test` + `npm run test:visual` zelené po každém tasku (vizuální regrese smí být přechodně degradovaná jen mezi Task 3 a Task 5 v MAIN pohledu, strukturální checky musí projít vždy).
- **Commit message česky, krátce, bez footerů** (žádné Co-Authored-By). Testy/audity v izolovaných instancích (vlastní port, nikdy nesahat na server :3000).

- [ ] **Step 1: Extrahovat planetTargets.js**

Vytvoř `src/planetTargets.js` — přesuň `buildTargetsForPlanet`, `_cache`, `getPlanetTargets` a reset ze `solarWind.js` beze změny logiky:

```js
// planetTargets — povrchové cíle teček planet (sdílí formace/akrece).
// Přesunuto ze solarWind.js (V4.4 F3): targets nejsou vlastnost větru,
// ale planety samotné.
import { fibonacciSphere } from './geometry.js';
import { PHASE } from './phase.js';
import { sampleColor, sphericalUV } from './textureUtils.js';

function buildTargetsForPlanet(planet, imageData) {
  const targets = [];
  const surfacePts = fibonacciSphere(planet.tickCount, planet.radiusPx * 1.02);
  for (const off of surfacePts) {
    const [u, v] = sphericalUV(off[0], off[1], off[2], planet.radiusPx * 1.02);
    targets.push({
      localOffset: { x: off[0], y: off[1], z: off[2] },
      color: sampleColor(imageData, u, v),
      phase: PHASE.ON_PLANET,
    });
  }
  return targets;
}

const _cache = new Map();

export function getPlanetTargets(planet, imageData) {
  if (_cache.has(planet.id)) return _cache.get(planet.id);
  const targets = buildTargetsForPlanet(planet, imageData);
  _cache.set(planet.id, targets);
  return targets;
}

export function resetPlanetTargets() {
  _cache.clear();
}
```

V `solarWind.js` smaž lokální kopie a importuj `getPlanetTargets` z `./planetTargets.js`; `resetSolarWind()` deleguje na `resetPlanetTargets()`. Chování appky se nesmí změnit.

- [ ] **Step 3: Implementovat spawnFromDisk**

Do `src/particles.js` vedle `spawnFromSun` (stejná struktura zápisů do polí — zkopíruj tělo `spawnFromSun` a uprav začátek):

```js
  /**
   * Emise z disku (akrece V4.4 F3) — jako spawnFromSun, ale zdroj je explicitní
   * pozice v disku (okolí planety), start barva = protoplanetární prach.
   */
  spawnFromDisk(sourceIdx, sourcePos, finalTarget, finalTargetLocal,
                finalColor, ownerIdx, finalPhase, currentTime, travelTime,
                finalAlpha = 1.0, finalSize = null) {
    const i = sourceIdx;
    const sx = sourcePos.x, sy = sourcePos.y, sz = sourcePos.z;
    this.position[3*i] = sx; this.position[3*i+1] = sy; this.position[3*i+2] = sz;
    // Prachová šedo-modrá (stejná paleta jako disk), final color se lerpne během letu.
    this.color[3*i] = 0.5; this.color[3*i+1] = 0.55; this.color[3*i+2] = 0.68;
    this.alpha[i] = 0.8;
    const tx = finalTarget.x, ty = finalTarget.y, tz = finalTarget.z;
    this.target[3*i] = tx; this.target[3*i+1] = ty; this.target[3*i+2] = tz;
    this.velocity[3*i]   = (tx - sx) / travelTime;
    this.velocity[3*i+1] = (ty - sy) / travelTime;
    this.velocity[3*i+2] = (tz - sz) / travelTime;
    this.postArrivalTarget[3*i] = tx; this.postArrivalTarget[3*i+1] = ty; this.postArrivalTarget[3*i+2] = tz;
    this.postArrivalColor[3*i] = finalColor[0]; this.postArrivalColor[3*i+1] = finalColor[1]; this.postArrivalColor[3*i+2] = finalColor[2];
    this.postArrivalAlpha[i] = finalAlpha;
    this.localOffset[3*i] = finalTargetLocal.x; this.localOffset[3*i+1] = finalTargetLocal.y; this.localOffset[3*i+2] = finalTargetLocal.z;
    this.arrivalTime[i] = currentTime + travelTime;
    this.owner[i] = ownerIdx;
    this.ownerAlpha[i] = this.ownerAlphaMul[ownerIdx];
    this.phase[i] = PHASE.FLYING;
    this.finalPhase[i] = finalPhase;
    this.size[i] = finalSize !== null ? finalSize : 6.0;
  }
```

```js
// Narativní fáze, ne přesné datování (out-of-scope dle specu §2).
const STAGES = [
  { start: 0,    label: 'Sluneční mlhovina se hroutí',            age: 'před 4,6 mld let' },

  { start: 22,   label: 'Dnes',                                   age: '' },

export function timelineAt(tSec) {

```
