# Dots

## Typ projektu: generic

## Pravidla pro Claude Code

- Bud strucny, ukazuj jen zmenene casti kodu
- Neprepisuj cele soubory, pouzij Edit tool
- Pred kazdou zmenou precti soubor, at vidis aktualni stav
- Commit message pis cesky
- Mluv česky i v konverzaci, neformálně
- Když je záměr jasný, jednej — neptej se zbytečně
- **Do commitů ani do pull requestů nepřidávej patičky** — žádné
  `Co-Authored-By` ani „Generated with Claude Code"

> Tahle pravidla musí být v repu, ne jen v globálním nastavení. Na
> `claude.ai/code` se konfigurace z pracovní stanice nenačte a bez nich
> by Claude odpovídal anglicky a podepisoval commity.
